SCADA BONT - PAKET PC2 REALTIME SYNC
====================================

PC2 harus menggunakan alamat IP 10.100.163.149.
PC1 menggunakan alamat IP 10.100.163.150.

Cara memasang:
1. Ekstrak seluruh folder ini di PC2. Jangan menjalankan EXE langsung dari ZIP.
2. Tutup SCADA lama di PC2.
3. Klik kanan MULAI_PC2.cmd lalu pilih Run as administrator.
4. Izinkan konfirmasi Windows. Skrip hanya membuka TCP 5001 dari PC1
   10.100.163.150 dan kemudian menjalankan aplikasi SCADA PC2.

Cara kerja:
- Edit + Save dari Parameter Setting, rectangle SCADA, atau Monitor TV di PC1
  diterapkan ke PC2 sekitar 1-2 detik.
- Edit + Save yang sama dari PC2 diterapkan kembali ke PC1 sekitar 1-2 detik.
- Cancel/Close tanpa Save tidak mengubah file sehingga tidak disinkronkan.
- Lampu breaker mengikuti CBZ8000: YX logis 1 berwarna merah/closed;
  YX logis 0 berwarna hijau/open setelah konfigurasi Reverse diterapkan.
- Jika RTU offline atau nilai YX belum diterima, breaker berwarna abu-abu
  dengan tanda ?; status ini tidak dianggap open maupun closed.
- CommunicationConfig.json tidak disinkronkan agar identitas PC1/PC2 tidak tertukar.
- Jika dua PC menyimpan file yang sama persis pada saat bersamaan, kedua PC
  akan memakai satu versi pemenang yang sama agar tidak terjadi loop bolak-balik.

File aplikasi:
SCADA BONT - PC2 REALTIME SYNC.exe
